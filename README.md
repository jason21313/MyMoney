# MyMoney

A multi-feature financial planning and tracking app meant to ease the stress of finances through simple yet effienct app design

## Built With

- Python
- SQLite
- CustomTkinter
- Pandas

## Features

- Secure Relational Login Database
- Budget Planner with descriptive Graphical Displays
- Expense Tracker that allows for Multi-Account Recording
- Savings Planner and Goal Setter
- Payment Tracker with In-App Reminders
